JanchaPass 운영자 안내

이 페이지는 공개 안내 페이지이며 관리자 콘솔이 아닙니다.

API 비밀키, 사용량, 운영 설정은 공개 GitHub Pages에서 관리하지 않습니다. 관리자 접근은 Cloudflare Zero Trust 또는 별도 인증된 관리 서버에서만 제공해야 합니다.

네이버 검색 Client ID와 Client Secret은 Cloudflare Worker Secrets에만 등록하세요. 지도용 브라우저 Client ID는 config.js에 넣을 수 있으나 등록 도메인 제한을 적용하세요.

관리자 인증 시스템 구축 전까지 이 주소에 비밀정보나 관리 기능을 배치하지 마세요.
